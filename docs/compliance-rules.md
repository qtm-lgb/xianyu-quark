## 二、两类必查词

### 1. 绝对化用语（广告法第九条）

```
最全  最新  第一  唯一  100%  彻底  顶级  最强  最好  最佳
国家级  世界级  史上最  全网最
```

标题里出现任一个，闲鱼可能直接判违规删商品（**不通知，等发现时已经没了**）。

### 2. 平台重点管控词

```
换脸  深度伪造  faceswap     # AI 换脸，肖像权 + 深度伪造
破解  破解版  激活  解锁  会员版  VIP破解   # 软件破解
暴力破解  实名释放  解封       # 违法用途
电子印章  印章制作  公章        # 伪造公文
盗版  磁力  torrent           # 侵权
敏感词  刷单  代练              # 平台生态违规
```

## 三、代码层面的三道防线

```
1. src/listing.js
   HIGH_RISK  —— 高危词替换表（换脸->形象素材 等）
   ABSOLUTE   —— 绝对化用语替换表（最全->合集 等）

2. src/compliance.js
   FORBIDDEN  —— 禁用词清单
   checkListing() / filterPublishable()
   校验：禁用词 / 绝对化用语 / skipPublish 标记 / penalized 标记 /
         标题超长 / 缺少有效链接

3. 所有发布入口都过 src/compliance.js
   - src/publish_xianyu.js       （Playwright 网页发布）
   - tools/yd_publish_items.js   （Ydisks API 发布）
   - tools/yd_setup_courses.js   （自动发货规则配置，也跳过被处罚商品）
```

## 四、被处罚商品的标记方式

在 `data/listings.json` 里加字段：

```json
{
  "skipPublish": true,
  "penalized": true,
  "note": "2026-11-07 被平台处罚",
  "itemIdBeforePenalty": "1097239610827"
}
```

- `skipPublish` —— 不发布
- `penalized` —— 被平台处罚过，**连自动发货规则都不配**
- `itemIdBeforePenalty` —— 留个记录，方便你在 APP 里找并下架

## 五、网页版的限制（为什么有些操作只能 APP 做）

| 操作 | 网页版 | 说明 |
|---|---|---|
| 发布商品 | ✓ | 但分类受限，见下 |
| **改标题** | ✓ | `https://www.goofish.com/publish?itemId=<id>` 可载入并重发 |
| **下架 / 删除商品** | ✗ | 列表页和商品页都没有按钮，只能 APP 操作 |
| 申诉处罚 | ✗ | 只能在闲鱼 APP（我->设置->帮助与客服->申诉） |

### 分类限制

网页版发布时，分类候选由**标题语义**决定（服务端固定推荐 10 个，无法搜索）：

- ✓ `电子资料`（channel_cat_id=202036301）—— 网页版可发
- ✗ `AI视频工具/服务`、`AI设计工具/服务`、`AI办公提效工具` 等 —— **网页版不支持**，
  点发布会被拦：「网页版暂不支持发布此分类，请使用闲鱼APP扫码发布」

换标题**改变不了**候选（同一个标题始终给同样 10 个）。
若某个标题的候选里没有「电子资料」，就发不了，只能改标题语义或走 APP。

## 六、新增商品的自检流程

```bash
# 1. 生成文案后先看合规
node -e "
const {filterPublishable,reportBlocked}=require('./src/compliance');
const l=require('./data/listings.json');
const {ok,blocked}=filterPublishable(l);
console.log('可发布 '+ok.length+'/'+l.length);
console.log(reportBlocked(blocked));
"

# 2. 检查所有在售商品的标题是否含风险词
node tools/check_titles.js

# 3. 抽查链接是否还有效
node src/probe_quark.js <链接1> <链接2>
```

### 标题自查清单

- [ ] 没有绝对化用语（最全/最新/第一/唯一/100%…）
- [ ] 没有平台管控词（换脸/破解/激活/解锁/敏感词/印章…）
- [ ] 长度 ≤ 30 字
- [ ] 断词处不切碎数字（「108集视频」不能变成「10」）
- [ ] 首行是标题，其余是正文（发布页只有「宝贝描述」一个富文本框）
- [ ] 分类候选里有「电子资料」（否则网页版发不了）

## 七、给运营的提醒

1. **平台处罚不通知**。商品被删了往往是你自己从「我发布的」里发现少了。
   建议每天看一眼在售数量（`node tools/check_titles.js` 会输出商品数）。
2. **一次批量发 30+ 个同质商品容易触发批量审核**。分批发、隔天发更稳。
3. **同质化标题也会被关联处罚**。一个被删，同批的相似标题可能被连带处理。
4. **别在标题里蹭平台热词**。用「合集/资料/教程」这类中性词比蹭词安全得多。
